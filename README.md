# Student Laptop Finder

SW302 Assignment 2. Five-page responsive laptop catalogue with saved favorites, comparison, and two themes.

## Run

1. Run `npm install` in the project folder.
2. Run `npm run build` to generate `dist/output.css` (or `npm run dev` during editing).
3. Open `index.html` through a local server such as VS Code Live Server. Do not open it with `file://` because the app fetches JSON.

## Pages

- `index.html` – home statistics
- `laptops.html` – search, filters, sorting and cards
- `details.html?id=1` – a laptop's full details
- `favorites.html` – saved laptops and price totals
- `compare.html` – select 2–4 favorites for comparison

The laptop records are fictional sample data, and the assets are local illustrative SVG laptop images rather than product photos. Favorites, comparison selection, and theme are saved in browser localStorage.
